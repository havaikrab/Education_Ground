При успешной отправке post-запроса на subscribe-эндпоинт пользователь получает платежную ссылку.
После оплаты или при истечении срока платежной сессии на сервер приходит вебхук от Stripe с
данными о состоянии сессии. В случае, если оплата прошла успешно, в БД на основании данных, полученных из
вебхука создаются объекты подписки и платежа.  
Stripe не может отправлять данные на http://localhost:8000/, поэтому в режиме разработки
используется утилита stripe-cli, позволяющая получать сведения о состоянии платежных сессий.
Актуальную версию stripe-cli можно скачать по ссылке:  
https://github.com/stripe/stripe-cli/releases/tag/v1.43.7  

Для получения вебхуков необходимо запустить stripe-cli в отдельном терминале с помощью команды:  
stripe listen --forward-to http://localhost:8000/webhook/  
При успешном запуске stripe-cli покажет секретный ключ, разработчику необходимо удостовериться,
что полученный ключ совпадает с переменной STRIPE_WEBHOOK_SECRET в файле .env .
